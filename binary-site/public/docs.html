📖 Documentação

Cada usuário tem um SID e uma lista de bytes (até 256). O SID vai sempre no header da request.

Endpoints

MétodoRotaO que faz
POST/data/binary/registerRegistra um ID. Corpo opcional: {"sid":"meu_id"}
GET/data/binaryLê o byte 0 → {"value":"00000000"}
GET/data/binary/:indexLê o byte do índice (0–255)
GET/data/binary/allLê todos os seus bytes
POST / PUT/data/binary[/:index]Escreve {"value":"10101010"} (exatamente 8 bits)

curl

# registrar
curl -X POST https://SEU-APP.onrender.com/data/binary/register \
  -H "Content-Type: application/json" -d '{"sid":"1234"}'

# escrever
curl -X POST https://SEU-APP.onrender.com/data/binary \
  -H "SID: 1234" -H "Content-Type: application/json" -d '{"value":"10101010"}'

# ler
curl https://SEU-APP.onrender.com/data/binary -H "SID: 1234"

JavaScript

const r = await fetch("/data/binary/3", {
  method: "POST",
  headers: { SID: "1234", "Content-Type": "application/json" },
  body: JSON.stringify({ value: "00001111" })
});
console.log(await r.json()); // { value: "00001111" }

Roblox (HttpService)

local HttpService = game:GetService("HttpService")
local res = HttpService:RequestAsync({
  Url = "https://SEU-APP.onrender.com/data/binary",
  Method = "GET",
  Headers = { ["SID"] = "1234" },
})
print(HttpService:JSONDecode(res.Body).value)

Erros comuns

401Sem header SID ou SID não registrado
400Valor que não tem exatamente 8 caracteres 0/1, ou índice inválido
404Esse índice ainda não foi escrito
409SID já em uso ao registrar
429Muitas requisições (limite por IP)
