📖 Documentation

Each user has a SID and a list of bytes (up to 256). The SID always goes in the request header.

Endpoints

MethodRouteWhat it does
POST/data/binary/registerRegisters an ID. Optional body: {"sid":"my_id"}
GET/data/binary/generateSuggests a random SID that is available right now (not reserved until you register it)
GET/data/binaryReads byte 0 → {"value":"00000000"}
GET/data/binary/:indexReads the byte at the given index (0–255)
GET/data/binary/allReads all your bytes
POST / PUT/data/binary[/:index]Writes {"value":"10101010"} (exactly 8 bits)

Expiry and accounts

A SID that isn't read or written for 3 days is deleted along with its bytes. Every request that uses the SID resets the timer. Every SID is unique, so two users can never share one.

Registering through the API creates an anonymous SID. To see and manage all your SIDs, create an account and create them there.

curl

# register
curl -X POST https://YOUR-APP.onrender.com/data/binary/register \
  -H "Content-Type: application/json" -d '{"sid":"1234"}'

# write
curl -X POST https://YOUR-APP.onrender.com/data/binary \
  -H "SID: 1234" -H "Content-Type: application/json" -d '{"value":"10101010"}'

# read
curl https://YOUR-APP.onrender.com/data/binary -H "SID: 1234"

JavaScript

const r = await fetch("/data/binary/3", {
  method: "POST",
  headers: { SID: "1234", "Content-Type": "application/json" },
  body: JSON.stringify({ value: "00001111" })
});
console.log(await r.json()); // { value: "00001111" }

Roblox (HttpService)

local HttpService = game:GetService("HttpService")
local res = HttpService:RequestAsync({
  Url = "https://YOUR-APP.onrender.com/data/binary",
  Method = "GET",
  Headers = { ["SID"] = "1234" },
})
print(HttpService:JSONDecode(res.Body).value)

Common errors

401Missing SID header, or SID not registered / expired
400Value is not exactly 8 characters of 0/1, or invalid index
404That index has not been written yet
409SID already taken when registering
429Too many requests (per-IP limit)
